Designed from the exploit outward

Not a generic file browser
with an exploit bolted on.

Every layer—from container discovery to preview and export—is designed around the real access behavior of bad_query.

01

Container discovery

Indexes application, App Group, plugin, internal daemon, system data, and System Group paths with direct access or fsgetpath fallback.

Capability-aware · No computer-side mapping
02

Per-operation access

Acquires the narrow sandbox extension needed for an operation and releases it immediately afterward.

Explicit lifetime · Diagnostic logging
03
◉

App-first workspace

Start from a grid or list of Apps. On iPad, inspect properties beside the file list; on iPhone, move through a focused full-screen flow.

Adaptive navigation · Remembered layout
04
↗

Guarded file workflow

Export files or recursive Markdown listings. Explicit replacement creates a versioned backup and verifies the write before offering restore.

SHA-256 verified · Safety backup on restore

Compatibility

Built for the
narrow window.

Vellune supports iOS and iPadOS 26 through 27 beta 3. This is a deliberately conservative range based on the versions implemented and tested in Vellune—not merely the broader range reported by the upstream proof of concept.
